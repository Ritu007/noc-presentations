Address Translation
  • PCIe devices send memory requests using their own address space (a PCIe bus address or I/O Virtual Address) — not the actual system memory address.
  • The CHI-based NoC and system memory use System Physical Addresses, so they cannot directly understand the address sent by the PCIe device.
  • RN-I checks the incoming address and, if required, works with the IOMMU or an address translation table to find the corresponding System Physical Address.
  • The translated physical address is inserted into the CHI request, ensuring it is routed to the correct destination within the CHI-based NoC.
  • This translation lets PCIe devices and the CHI-based NoC communicate correctly, even though they use different address spaces.
Ordering Enforcement
  • Tracks outstanding PCIe requests to identify which ones have ordering dependencies.
  • Translates requests into CHI transactions, understanding the ordering rules PCIe requires.
  • Delays dependent requests — or holds responses/completions — when necessary to avoid violating order.
  • Reorders CHI responses so PCIe completions are returned in the correct protocol-defined order.
  • Balances performance and correctness — ordering is preserved only when necessary, letting independent transactions execute in parallel.
