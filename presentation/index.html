2. What the server does

Every message finds its C++ function

start-up: read config.json (port 8080, 4 request threads, CORS origins) · register features · bind port 8080 (Windows also checks it is free)
POST/api/v1/runs→RunsController::Createreplies 202 Accepted; the run continues in the background
GET/api/v1/runs/{id}→RunsController::Get
GET…/results→RunsController::Results
WS/ws/v1→live updates
app.run(): message in → handler → reply, until Ctrl+C

3. Why Drogon

A C++ library that does the networking

  1. Written in C++, like CoreCore is linked in as a library and called directly. No bridge, no second language.
  2. HTTP, WebSocket and threads in oneWe write only the handler functions.
  3. Fast, maintained, cross-platformRuns on Windows and Linux.
