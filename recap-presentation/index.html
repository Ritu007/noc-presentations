Noxim
  • Built on SystemC
  • Designed for fast cycle-accurate NoC performance studies
  • Parameters specified via CLI or config files
  • Good for synthetic traffic, parameter configs, and basic congestion/routing studies
BookSim
  • C++ standalone NoC simulator
  • Focus on detailed router micro-architecture
  • Extremely flexible with topology, routing, traffic patterns, router internals, and traffic manager configuration
  • Validated against RTL router models
Garnet (gem5)
  • Not a standalone NoC tool
  • NoC component inside gem5's Ruby memory system and full-system simulator
  • Provides cycle-accurate NoC modeling within a complete system with cache coherence, CPU cores, memory
  • NoC traffic arises from real execution, not just synthetic packets
Nirgam
  • Built on SystemC
  • Discrete-event, cycle-accurate simulator
  • Good for routing studies across multiple topologies
  • Includes mesh, torus, irregular topologies, and plug-in support for custom routers
Tejas
  • Built in Java
  • Versatile micro-architectural simulator rather than a standalone NoC-only tool
  • Includes a generic NoC model that can connect cores, cache banks, directories, and memory controllers inside a multicore memory system simulation

Recommendation
  • Custom C++ if goal is speed and scale (e.g., running millions of cycles on a 64-node NoC to get latency numbers).
  • SystemC if goal is standardization and verification (e.g., building a Golden Model to verify the actual Verilog implementation of the NoC).
