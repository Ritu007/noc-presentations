Router pipelinefive stages per channel, in two phases every cycle

IQ
Input Queuing
Flit is written into a VC buffer; VC state becomes Routing.
→
RC
Route Compute
Output port is computed by the routing algorithm.
→
VA
VC Allocation
A downstream VC is reserved for the output port.
→
SA
Switch Allocation
The flit arbitrates for a crossbar grant.
→
ST
Switch Traversal
The flit crosses the crossbar into the output buffer.
EVALUATE
Stamps the cycle in which each stage should run (current cycle plus the stage latency). VA and SA also poll their requests and generate the grants here.
UPDATE
Performs the actual state change, only for flits whose timestamp has matured.
4 channels run their own pipeline: REQ · RSP · DAT · SNP
